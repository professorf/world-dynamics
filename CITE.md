# How to cite

If you use this code or its validation in your work, please cite it, and please also cite Forrester's book, where the model comes from.

## This repository

The code is archived on Zenodo. The DOI **10.5281/zenodo.23126731** stands for all versions and always resolves to the latest release. To cite exactly version 1.0.0, use **10.5281/zenodo.23126732**.

**APA (7th ed.)**

> Flor, N. V., & Claudia (Claude Interactive Assistant). (2026). *World2 in Python: A staged, validated translation of Jay W. Forrester's World Dynamics model* (Version 1.0.0) [Computer software]. Zenodo. https://doi.org/10.5281/zenodo.23126731

**BibTeX**

```bibtex
@software{flor_world2_python_2026,
  author  = {Flor, Nick V. and {Claudia (Claude Interactive Assistant)}},
  title   = {World2 in Python: A Staged, Validated Translation of Jay W. Forrester's World Dynamics Model},
  year    = {2026},
  version = {1.0.0},
  doi     = {10.5281/zenodo.23126731},
  url     = {https://github.com/professorf/world-dynamics},
  note    = {Claudia (Claude Interactive Assistant) is Claude, an AI model by Anthropic}
}
```

Claudia is Claude, an AI model made by Anthropic. Some journals and style guides do not allow an AI system to be listed as an author. If yours is one of them, cite the repository under Nick V. Flor alone and describe Claude's contribution in your acknowledgments or methods section, for example: "The translation was developed by Nick V. Flor with Claude, an AI model by Anthropic."

## The original model

**APA (7th ed.)**

> Forrester, J. W. (1973). *World dynamics* (2nd ed.). Wright-Allen Press. (Original work published 1971)

**BibTeX**

```bibtex
@book{forrester_world_dynamics_1973,
  author    = {Forrester, Jay W.},
  title     = {World Dynamics},
  edition   = {2},
  publisher = {Wright-Allen Press},
  address   = {Cambridge, MA},
  year      = {1973},
  note      = {First edition published 1971}
}
```

The equations translated here are from Appendix B of the 2nd edition, and the validation figures are from Chapter 4.
